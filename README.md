# Megavites storefront

A modern, responsive storefront concept for Megavites.co.uk, built as a static single-page experience.

## Included

- Responsive desktop and mobile design
- Product category navigation
- Popular-products grid
- Interactive wishlist controls
- Shopping basket drawer with add/remove actions
- Search dialog
- Sticky navigation
- Progressive metallic finishes through [MetalliCSS](https://github.com/MikaeI/metallicss)

## Run locally

```sh
npm start
```

Open the local address printed by `npx serve`.
